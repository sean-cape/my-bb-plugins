A keyboard-first project and thread picker, replacing the projects and threads in bb's sidebar.

## What you get

- **No thread list in the sidebar.** bb's sidebar keeps its navigation and footer; projects and threads move into the picker.
- **Double Shift opens the picker.** Tap Shift twice (with the Double Shift plugin installed), or bind the Switch project command under Settings → Keyboard; it has no default shortcut. It opens on Unread. On the left, a mini sidebar: Open folder…, Unassociated, Pinned (with a count), and Unread (finished threads with a response you haven't opened yet, plus Claude sessions with a prompt running, across every project; automation runs are left out), then your current project under its own Current label, then the rest of your projects, most recently active first, each with a working or attention glyph and how long ago it was last active. On the right, a header naming the selected entry and its thread count, then its threads, nested under their parents and grouped: Needs you (waiting on an answer, a failed send, or an unread response), Running, then Today, Yesterday, Past week, and Older. Unread is split into Needs you and Running; Pinned keeps your pin order. While you're in the threads column, a preview pane opens beside it with the highlighted thread's full title, project, branch, and pull request status above the end of its conversation; previewing doesn't mark it read. Press `l` again to move into the preview and scroll it with `j`/`k`, Ctrl+D/Ctrl+U, Ctrl+F/Ctrl+B, Ctrl+E/Ctrl+Y, and `gg`/`G`; `h` goes back to the threads.
- **Always shows where you are.** The search bar's right side names your current project and thread. In the lists, the current project and the open thread carry a bar in the project's color; Unassociated gets it when you're in a personal thread. The current project is the open thread's project, else the project whose screen is open, else the active project.
- **Find threads, not just projects.** `/` filters projects by name; when any thread's title or branch contains every word you typed, a Matching entry after the projects lists those threads across all projects.
- **Keyboard first, vim style.** `j`/`k` move, `h`/`l` switch columns, `gg`/`G` jump to the top or bottom, `/` filters projects and finds threads (Esc clears it), `Enter` opens a thread (or moves into a project's threads), `p` pins or unpins the highlighted thread, `r` marks it read (dropping it from Unread), `d` (shown as delete) archives it, so it can still be restored from Settings → Archived threads, `u` undoes the archive while bb's "Thread Archived" toast is up (anywhere in bb, not just the picker), `n` starts a thread in the selected project, `Esc` closes. The footer lists the keys that do something in the focused column. Arrow keys, Tab, and Ctrl+N/Ctrl+P work too. A mouse works as well; the thread under the pointer is the highlighted one.
- **Open a folder as a project.** Choose Open folder… for the system folder dialog, or press `/` and type a path such as `~/dev/app`. A folder that is already a project selects it.

## How it works

The picker opens on Unread, with your current project one `j` below it; if the thread you're viewing is unread, it's highlighted on the right. Opening a thread makes its project the active one (Unassociated threads don't), which is what the picker starts on. It's a synced preference, so every window agrees.

Pick it under Settings → Appearance → Sidebar, or disable the bundled Thread list plugin; owning that slot is what keeps bb's own list out of the sidebar. `bb grouped-thread-list prefs` reads and changes the active project.
